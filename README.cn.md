# gitv

[English version](./README.md)

gitv is a terminal-based viewer for GitHub issues. It allows you to view and manage your GitHub issues directly from the terminal.

![gitv](https://repo.x-cmd.io/gitv.svg?lang=zh)

## 安装

```sh
x install gitv
```
